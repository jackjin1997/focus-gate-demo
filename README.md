# 专注之门

一个纯前端、只使用本地样例数据的 FocusEvent 交互样机。它演示门外准备、守门检查、门内专注、单次敲门、覆盖中断和有限交接单。

## 产品边界

- 不连接飞书，不申请真实权限。
- 不修改飞书状态、日历或消息。
- 不发送自动回复，样机中的所有内容都是本地示例。
- 门内不展示消息数量、发送人、未读徽标或动态风险分数。

## 本地运行

需要 Node.js 20 和 pnpm 10。

```bash
pnpm install
pnpm dev
```

打开 `http://localhost:5173`。

## 验证

```bash
pnpm test
pnpm typecheck
pnpm build
```

## 体验分支

进入门内后，右上角的“样机控制”可以触发一次敲门，或模拟飞书覆盖中断。敲门只会出现一次；覆盖中断后，样机立即撤下“无需处理”的承诺。
